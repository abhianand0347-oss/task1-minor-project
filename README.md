# TaskFlow – Task Management Website

# About the Project
TaskFlow is a simple website that helps users manage their daily tasks.

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

# Features
- Add new tasks
- Edit and delete tasks
- Mark tasks as completed or pending
- Search tasks
- Filter and sort tasks
- View task details on the dashboard

# How to Run
1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
